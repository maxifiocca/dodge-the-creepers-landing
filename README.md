# Dodge the Creepers — landing page

Landing page estática en español para presentar *Dodge the Creepers*, hecha con HTML y CSS. No requiere dependencias ni proceso de compilación.

## Verla en local

El sitio está dentro de `docs/`. Podés abrir `docs/index.html` directamente en el navegador. Para servirlo en local desde la carpeta raíz, ejecutá:

```powershell
python -m http.server 8000
```

Después abrí <http://localhost:8000>.

## Personalizar

- Editá los textos y estilos en `docs/index.html`.
- Reemplazá las imágenes de `docs/assets/` por capturas y sprites de tu propia versión si los tenés.
